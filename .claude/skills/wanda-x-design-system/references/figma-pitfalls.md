# Figma MCP / Plugin API — пастки (перевірено на файлі Wanda X)

Читати, коли щось падає або перед складною операцією (міграція, перенесення шарів у мейні, Export).

## Доступ і завантаження
- Конектор працює від `evgeniy.bogdanov@ys.bet`. Перед змінами — пробний запис; `read-only mode` = немає Can edit.
- `get_metadata` без nodeId показує лише першу сторінку; список сторінок — `use_figma` → `figma.root.children`.
- Одна сторінка = один `use_figma`; кілька — паралельні виклики (read-only — батч по 4–7 сторінок).
- Сторінки вантажаться ліниво: перед `findOne` всередині інстансу з іншої сторінки — `await page.loadAsync()`.
- `node.devStatus` недоступний — статус Ready for dev вручну.
- `componentPropertyDefinitions` кидає помилку на зламаних наборах — завжди `try/catch`; помилка = дефект.
- Корінь INSTANCE повертає `boundVariables` мейна — не плутати з прив'язками локальних шарів.
- Помилка посеред `use_figma` відкочує весь скрипт; `return` раніше — зміни до нього лишаються.

## MrBet Black (стилі `heading/*`)
- Конектор не має шрифту: `appendChild` / `insertChild` вузла з таким текстом падає `unloaded font "MrBet Black"`, створений інстанс лишається на корені — **прибирати залишки**.
- Перенести вузол: `const g = figma.group([node], targetParent, index); figma.ungroup(g);` (без перевірки шрифту). Копія — `node.clone()` → group/ungroup.
- Вставити новий: тимчасовий інстанс без MrBet (`Spinner` 47531:173652) → `swapComponent(<Layout/xl | Heading …>)` → `unlockAspectRatio()`, `resize(w, main.height)`, `FILL` / `FIXED`.
- `Heading` у слоті — placeholder + swap **після** того, як контейнер уже в слоті.
- Текст MrBet (characters, стиль, autoResize) змінити не можна; `fills`, `layoutSizing*` — можна, але **ширина не перераховується** (після clone / зміни Breakpoint `Title` лишається старої ширини) — перелічити у відповіді, що поправити вручну.
- Обхід через тимчасовий шрифт (`fontName = Inter` → `characters` → `setTextStyleIdAsync(heading/*)`) **не працює**: стиль не повертається, текст лишається Inter — не пробувати. Готові MrBet-тексти в старих макетах — це звичайні TEXT, не `Heading`, перенести їх у `Heading` не можна. Єдиний шлях для конектора — шрифт `MrBet` (Black) має бути доступний Figma (shared font організації).
- Скинути чужий текст `Heading` (напр. «News» після clone): `resetOverrides()` міняє лише дані — на канвасі лишається старий текст. Працює тільки заміна на свіжий інстанс (Spinner → `swapComponent`); у свіжого Secondary вимкнути Boolean-и (іконка, All, стрілки). Тому сети **не клонувати з іншої сторінки** — Heading брати свіжим.
- `Button` має `maxWidth = 420` — у модалках xl на всю ширину: `btn.maxWidth = null` + FILL.

## Вузли, клони, слоти
- Після `group/ungroup` вузла всередині слота клонованого `Layout/*` у **наступному** скрипті діти цього фрейму — биті проксі (ім'я / розмір самого `Layout/*`): `resize()` на такому «дитині» змінює **весь `Layout/*`**. Перед правкою перевіряти `node.name` / `width`; усе правити в тому ж скрипті, де переносили.
- `Empty`: при `Button = false` інстанс кнопки зникає з `children` — спершу `Button = true`, потім шукати й міняти текст.
- Button на `background.slateDark1`: `Text [Invert]` / `Tertiary [Invert]` нечитабельні в MB — для текстової CTA на темній картці `Text Accent`.
- Порівнювати вузли **за `id`**, не за об'єктом.
- `.children` вузла, перенесеного group/ungroup у слот інстансу, може повертати чужі вузли — брати `findAll(n => n.parent.id === parent.id)` або `getNodeByIdAsync`.
- `clone()` вузла зі слота інстансу з'являється на корені сторінки — повертати group/ungroup.
- Після clone / group-ungroup override-и тексту інстансів можуть злетіти до дефолту — перевіряти.
- Після злиття обгорток може з'явитись `minWidth/minHeight` — обнуляти.
- Override `constraints` в інстансі заборонений; hug-висота інстансу — `primaryAxisSizingMode = 'AUTO'`. Накладання блоків — від'ємний `itemSpacing`.
- `clone()` варіанта губить `componentPropertyReferences` і робить із SLOT звичайний FRAME → відновити посилання, видалити FRAME, створити слот заново з `slotContentId` = ключ наявної властивості. Клон варіанта — `set.appendChild(clone)`.
- `figma.createSlot` не існує — `componentNode.createSlot()`; другий варіант: `slot.componentPropertyReferences = {slotContentId: key}`, дубль-властивість видалити.
- Прихований шар в інстансі не видно через `findOne` — дивитися `componentProperties`.
- Paint зі змінною: fallback-колір = реальне значення змінної (інакше рендер чорний).
- Скріншот мейна може бути кешем — перевіряти на іншому вузлі або даними.
- Темний фон з мертвою змінною — поломка макета, не привід для Inverted.

## Зміни в мейні
- Перенесення шарів у мейні (прибрати обгортку) **скидає override-и інстансів** (текст, swap, колір) → записати override-и всіх інстансів (plugin data `figma.root`) → змінити → повернути.
- Зміна дефолтного тексту в мейні перепише інстанси без override (там, де текст = дефолт) — спершу зафіксувати тексти.

## Аналіз використань
- `getInstancesAsync()` → сторінка, власник, вкладеність, override-и, фон-предок.
- `getInstancesAsync` **не повертає** пункти в слотах інстансів — шукати через інстанси контейнера.
- Вміст слотів інстансів: `getInstancesAsync` дає вузли, чий ланцюг `parent` обривається (`💠 Body`, `Main Area` з `parent = null`), а `page.findAll` у слоти інстансів **не заходить**. Шукати власною рекурсією по `children` (після `page.loadAsync()`), порівнюючи `getMainComponentAsync()`.
- Інстанси без PAGE-предка — залишки, ігнорувати.
- Вкладені копії оновлюються від мейна — міняти лише верхній рівень; список верхніх інстансів збирати **до** змін.

## Міграція на новий компонент
- `swapComponent` губить вміст слотів, якщо назви SLOT-властивостей різні → тимчасово перейменувати SLOT-властивості цілі на назви старого (`editComponentProperty`), після — назад. Boolean-и переносити явно.
- Інстанс усередині іншого мейна: після swap override-и зовнішнього мейна не застосовуються, вміст «зникає» (не видаляється — swap назад повертає). Такі автоматично не мігрувати.
- Скріншоти «до» / «після»; старий інстанс не видаляти, доки новий не перевірено.
- Команда видалила варіанти (напр. `Inverted=True`) → інстанси лишаються на «сиротах» з назвою `Set/…/<значення>` (`Table/Cell/sm/Left/True`), `main.parent = null`. Swap на живий варіант того ж набору зберігає слоти, тексти, Boolean-и (ключі властивостей ті самі), **але й override-и з мертвими змінними** — після swap аудит мертвих прив'язок.
- Мертвий override змінної на глибоко вкладеному інстансі (у слоті інстансу всередині мейна сторінки) `setBoundVariable(k, var)` **мовчки ігнорує** — `setBoundVariable(k, null)` знімає override, працює прив'язка компонента.

## Token Studio plugin data
- Ключі: `itemSpacing`, `paddingTop|Right|Bottom|Left`, `height`, `width`, `fill`, `borderColor`; радіус — **на кожен кут** `borderRadiusTopLeft|TopRight|BottomRight|BottomLeft` (один `borderRadius` → Inspect показує ⬡). Значення — `JSON.stringify("token.name")`.
- **Export перестворює змінні з новими ID** (і видаляє створені вручну, якщо їх нема в бренчі) → прив'язки мертві. Після Export: аудит мертвих прив'язок, переприв'язка за plugin data `tokens` на змінну `token.replace(/\./g,'/')`.

## Grid / клони (2026-11-04)
- Новий `layoutMode = 'GRID'` створює рядки `FLEX` → картки накладаються; одразу `gridRowSizes = rows.map(() => ({type: 'HUG'}))`.
- `clone()` фрейма зі слота інстансу може загубити TEXT (у дереві — «чужий» вузол з ім'ям `Layout/…`). Не видаляти «чужих» дітей — створити новий фрейм і зібрати заново.
- Пошук TEXT по `characters` у всьому сеті зачіпає й Sidebar / абзаци — шукати лише всередині свого фрейму за `id`.
- Новий `GRID`-фрейм створюється з рядками `FLEX` → картки накладаються. Одразу `gridRowSizes = rows.map(() => ({type:'HUG'}))`, дітям `layoutSizingVertical = 'HUG'`.
- `Modal/Default` (Title — MrBet) не вставляється `appendChild` у Section — тільки `group/ungroup`. Невдалий скрипт `use_figma` відкочується цілком — залишків нема, але перевіряти.
- Перемкнути режим XON (`setExplicitVariableModeForCollection`) конектор не може — падає на шрифті `Xon_028 Black`; XON перевіряє Андрей у Figma.
- Інстанс, перенесений `appendChild` у слот, отримує новий id — стара змінна мертва. Кнопки в Footer модалки — створювати свіжі інстанси того ж варіанта з тим самим текстом, старі `remove()`.
- `Table`: при `Show head = false` слот `Head` зникає з `children` — чистити / заповнювати слоти до вимкнення шапки; слоти брати через `t.children`, не `findAll`.
- `Empty` Card=True має MrBet Title — вставляти group/ungroup, текст — у `Description` (Title вимкнути).
- Section не вкладається в Section (`appendChild` падає на MrBet усередині) — старі Section-референси лише фарбувати / переставляти.
- Скриншот одразу після правки часто кешований — перевіряти розміри даними.
- `findAll` за назвою кнопки в Layout чіпляє і кнопки хедера / сайдбару — шукати тільки в `Main Area` / слотах.
- `component.resize()` після `primaryAxisSizingMode='AUTO'` фіксує висоту — після ресайзу ставити `layoutSizingVertical='HUG'`.
- Вузли всередині контенту слота **клонованого** інстансу (клон цілої Section) недосяжні: `findAll` їх не бачить, `.children` повертає биті проксі. Правити вміст до вставки в слот або перезаповнювати слот свіжим клоном.
- Клон вузла з MrBet лишати на місці (`clone()` кладе поруч з оригіналом) і переносити group/ungroup — `page.appendChild` падає.
- Напрямок (`layoutMode`) слота в інстансі не перевизначається — потрібен свій `Wrapper` усередині слота.

- GRID: `insertChild` нового елемента авто-розставляє клітинки (займає вільну) → після заміни ставити `setGridChildPosition(r,c)` з кінця (спершу останній); після цього `gridRowSizes` стає FIXED 1 → повернути `{type:'HUG'}` (без `value`).

## Імена властивостей і шкала токенів
- Ключі властивостей `Button` (і ін.) містять нерозривні пробіли (`\u00a0`) — `setProperties({'     ↳ 💠#27590:3': …})` падає «Could not find»; шукати ключ `Object.keys(i.componentProperties).find(k => k.endsWith('#27590:3'))`.
- Шкала `spacing.*` — 100 = 4 px (200 = 8, 300 = 12, 400 = 16, 600 = 24); `global.borderRadius`: xs 4 · sm 6 · md 12 · lg 20 · xl 24 — підбирати токен за значенням, не за назвою.
- MrBet-текст після clone / HUG конектор міряє запасним шрифтом → ширина занижена (91 замість 191), сусіди наїжджають. Ширину брати з оригіналу (FIXED) або ставити сусіда на новий рядок; `layoutWrap = WRAP` у вмісті слота не спрацював.
