# Learn component — команда оновила / додала компонент

Claude **лише читає і документує**, у Figma нічого не правити. Відхилення — питання, не виправлення.

## Тригери
| Фраза | Дія |
|---|---|
| «оновили / доробили / додали `<X>`» | повний цикл |
| «що змінилось у `<X>`?» | кроки 1, 2 (BASELINE), 4 — без переписування доків |
| «вивчи сторінку `<Y>`» | цикл для кожного набору сторінки |
| команда відповіла на питання | відповідь → «Рішення» в `components/<c>.md`, прибрати з питань |

## Цикл
1. **Знайти**: посилання → nodeId, або сторінка `↳ <Name>` → Section → набір.
2. **Знімок** `scripts/snapshot-component.js` через `use_figma` (read-only, спершу скіл `figma-use`):
   - `DIGEST=true` — для git → `snapshots/<c>.json` (kebab-case, однина; набори одного компонента — в одному файлі);
   - `DIGEST=true` + `BASELINE=<вміст snapshots/<c>.json>` — лише змінене;
   - `DIGEST=false` — повний знімок для вивчення (не в git; ліміт відповіді 48 КБ → `VARIANT_FROM`, `MAX_VARIANTS`); `LITE`, `COMPACT` — стискання.
3. **Скриншот** Section: стани, Inverted, MB / XON.
4. **Diff**: `python3 scripts/snapshot-diff.py snapshots/<c>.json` (vs останній коміт); `--summary <file>` — звести повний знімок.
5. **Записати** `references/components/<c>.md` за `_template.md`; значення токенів — з `tokens/system/`. Висновки Claude позначати **(спостереження)**, призначення не вигадувати.
6. **Звірити** з DoD (`rules/build-component.md` §6): кожен ❌ — рядок «Відхилення»; повторюване в кількох компонентах — спитати, чи це нове правило (`references/open-questions.md`).
7. **Реєстр** `references/component-registry.md`: статус, дата вивчення, дата експорту токенів, ID, к-сть варіантів.
8. `CHANGELOG.md` + коміт `learn(<c>): …` — знімок, `.md`, реєстр одним комітом.
9. Відповідь 3–8 рядків: що вивчено, що змінилось, відхилення, питання.

## «Характер» компонента (розділ у `.md`)
Роль і фон · що змінюється між станами · які частини інвертуються · MB vs XON · розміри і гнучкість ширини · вкладені компоненти, слоти, swap · чого свідомо не вміє.

## Статуси реєстру
`Ready for dev` · `Learned` (є знімок, `.md` за шаблоном, токени звірено) · `Changed` · `In progress (team)` (не вивчати) · `Rebuilt — review` · `Not started`.

## Чого не робити
Не писати у Figma · не переписувати старі рішення (нові — в кінець, скасовані — `~~…~~ — скасовано: …`) · не видаляти знімки вручну · «стану нема» ≠ помилка без DoD.
