# Core — жорсткі правила Wanda X (читати перед будь-якою роботою у Figma)

Коротко, без історії. Звідки взялось правило — `CHANGELOG.md` у корені репо (не читати без потреби).

## Режим роботи
- Figma змінюємо **лише на прямий запит** («зроби / прив'яжи / поправ»). «Чому / як краще» — спершу відповідь, без змін. Аудит = read-only.
- Старе **не видаляємо і не перейменовуємо** без прямого запиту; нове — поруч / праворуч.
- **Референси (`Preview`, `Design`, будь-які Section з дизайном від Андрея / команди)** — поки сторінка збирається, вміст не чіпати, лише читати. **Коли нові сети сторінки зібрано — референси теж застарілі**: чорна Section, назва `Old — <назва>`, у ряд `Old — …` одразу за сетами (`y = 0`, 600 між); вміст не змінювати.
- Після кожної дії — `get_screenshot` і коротка відповідь українською: що зроблено, що змінилось, питання. Не обіцяти неперевіреного.
- Відсутній токен не підміняти «схожим» без погодження — запропонувати або створити новий.
- Початок сесії: спитати, чи були зміни в Token Studio, попросити свіжий архів JSON → `tokens/system/` + diff (`rules/tokens.md` → Свіжий архів).

## Компоненти
- **Точна копія**: вигляд, розміри, кількість елементів, стани оригіналу; нові варіанти / слоти — тільки на запит.
- Перед правкою — найближчий еталон Ready for dev (`references/reference-components.md`).
- Тільки **інстанси** реальних компонентів, не імітація фреймом. Один компонент — одна сутність (дублікати зливаються).
- **Без TEXT-властивостей** (`✏️ Label`) — текст міняють в інстансі. Дефолти: текст `Label`, іконка `plus`, у списках 3 пункти.
- Стани логічні: `State = Default | Active | Open`. Розміри — малими, `xl` зверху → `xs` знизу.
- **Темний фон — режим колекції `Theme = Inverse`** на контейнері / слоті макета, **не варіант `Inverted`**. Нових `Inverted`-варіантів не робимо; наявні в старих компонентах — легасі.
- Орієнтація / дзеркалення варіантів — реальними розмірами, **не rotation**.
- Не плодити варіанти: різниця лише в gap / ширині → один компонент зі слотом.
- Квадратні елементи — `lockAspectRatio()` + токен лише на `height`.
- Рядкові компоненти — `height` size-токеном, лише горизонтальний падінг.
- **Картинки (ілюстрації, медалі, монети, фото) у компонентах і в попапах / слотах лейаутів — тільки порожній `Image/Single`** потрібного розміру (`Slot=False`, дефолтна заглушка). Самі картинки-приклади — **над Section компонента**: кожна над своїм варіантом, низ на 104 px вище Section (бібліотечні картинки — інстансом, растрові — фреймом із заливкою). **Інстанси в лейаутах повністю наслідують компонент** — картинок в `Image` не вставляємо, override-ів на `Image` немає.
- Документація — **тільки в скілі** (`references/components/<c>.md`); `description` у Figma порожній, нотаток на канвасі нема.
- Продуктові компоненти (Hall of fame, Cashbox …) — не в ДС.
- Іконки — **тільки `Static — Icons`** (`J3DHQyf6ARy401o7WywySC`), swap через `↳ 💠` (`references/icons.md`).
- Чужі бібліотеки змінних (`Colors/text`, `spacing/xxs` …) заборонені — тільки колекція `Product`.

## Структура шарів
- Auto layout всюди, де 2+ дочірніх; absolute — лише оверлеї / фон / бейджі.
- **Жодних зайвих обгорток — ніколи**: фрейм з одним дочірнім фреймом, `Wrapper` у `Wrapper` з тим самим напрямком — злити. Обгортка лише там, де інший напрямок / gap / padding / заливка.
- Шар без ролі — **`Wrapper`** (не Container / Window / Frame 123). Ряди з однорідним вмістом — за вмістом (`Cards`, `Benefits`, `Accordions`).
- Заголовок + опис — два TEXT прямо в батьківському фреймі: **`Title`** (один шар, Auto height) + **`Description`**.
- **Clip content off** на всіх своїх фреймах. **Жодних min / max** розмірів — тільки Hug / Fill / Fixed.
- **Fill, а не Hug**, якщо праворуч є вільне місце (картки в ряду, інпути в рядку; ціна / текст — Hug, кнопка — Fixed).
- Контент у рядку — **по центру по висоті** (`counterAxisAlignItems = CENTER`), якщо оригінал не вирівнює по верху.
- Неймінг — Title Case англійською, без `Property 1`, `Frame 123`, опечаток (деталі — `references/naming.md`).

## Токени
- Token Studio-токен **прямо на шар** (plugin data `tokens`) + однойменна змінна `Product`. Жодного hex / hardcode.
- Свій компонентний токен `<component>.*` для заливок, обведень, розмірів, радіусів; значення — alias (`fill.*`, `background.*`, `global.borderRadius.*` …) або `override.*`, не `core` / `map`; розміри й відступи в `stage` — числа (див. `rules/tokens.md`).
- **Колір тексту — глобальні `tt.*` напряму** (`tt.primary|secondary|tertiary`, `tt.accent1|2|3`, `tt.link`, `tt.success|warning|danger|info`), іконки / шеврони — `icon.*`; без компонентних. На темному — `Theme = Inverse` (сет `inverse` перевизначає `tt.*`).
- Типографіка — тільки стилі `text/*` (+ токен `typography` на шарі); тексти без стилю = дефект.
- Мінімум токенів: gap 0, прозора заливка, однакове значення в Default / Inverse — без окремого токена.
- Назви за властивостями (`table.filled.*` для `Variant=Filled`); `padding-h`, `padding-v`, `gap-v`; окремих `inverted.*` токенів не робимо — інверсію дає сет `inverse`.
- У групі JSON — спершу листки, потім підгрупи.
- **Не видаляти** токени — `$deprecated` з підказкою заміни.
- **JSON віддаємо тільки разом із прив'язками** в Figma + таблиця «токен → шар → властивість».
- Цикл JSON-handoff, Export, переприв'язка — `rules/tokens.md`.

## Section
- Компонент: сіра `#BBBBBB`, обведення чорне 10 % 1 px, радіус 2; назва = компонент; **80 px** від країв і між компонентами; основний компонент першим, під-компоненти під ним; варіанти в наборі — 16 / 16. Скрипт — `scripts/section-create.js`.
- Старе на лейаут-сторінках — **чорні** Section `#000000`, підпис `Old — <що>`. Оригінали компонентів — Section `Originals — <назва> (не використовувати)` поруч з новою; видаляти лише на запит і коли інстансів 0.
- **80 px з усіх боків — завжди**, перераховувати після кожної зміни вмісту.
